# Lessons

One line per missed bar: the class of miss, and the mechanism that now catches it.

- 2026-09-22 — A refusal allowlist named this package's exceptions but not the engine's (rpy2 `RRuntimeError`), so every R-side failure was masked. Now converted once at `engine.r_eval`; `test_an_unanticipated_r_error_reaches_the_caller_with_rs_message` pins the class, not an instance.
- 2026-09-22 — A lookup table that rounds to the nearest listed entry rounded every statistic in the unsafe direction (t quantile too small → CIs too narrow). Replaced with the exact function; `tests/test_t_quantile.py` checks every allowed n against an R-independent reference.
- 2026-09-22 — A diagnostic's baseline was "the first reported value", which is after the effect it measures had already acted (cycle-1 variance, post-selection). Baselines are now the pre-treatment state, tested through the tool on a one-cycle run.
- 2026-09-22 — A validation lived only inside the branch where it was first needed (`n_qtl_per_chr <= seg_sites` only with a SNP chip). Bounds that hold unconditionally are now checked unconditionally; each is tested through the MCP layer with its valid extreme as a positive control.
- 2026-10-16 — A benchmark keyed on theory, with bands sized for simulation noise, could not tell the textbook answer from its common shortcuts (infinite-population intensity, no Bulmer effect: 0 of 12 and 0 of 8 outside the band), so no arm needed a tool and none called one. `build_questions.py` now keeps a design only if every named shortcut lands outside its band, and `test_every_named_shortcut_misses_its_band...` recomputes the shortcuts rather than trusting stored flags.
- 2026-10-17 — A benchmark headline included a category whose bands one constant could pass (the category median of the key lands in 5 of 6 probability bands), so a right answer there did not show a simulation was run. `analyse.py` now scores a constant baseline per category through the real scorer, `build_questions.NOT_HEADLINE` holds what it disqualifies, and a test ties the two.
- 2026-10-17 — The top-level README said the benchmark questions are ones "closed-form theory gets wrong", while the best named formula lands in 15 of 34 bands, and two contamination disclosures sat under Reproduce. Class: benchmark copy written ahead of its own tables. Caught by a read-only audit of every README number against `summary.tsv` and `analysis.json`; no hook can judge the wording, so that audit runs before a benchmark write-up merges.
- 2026-10-16 — A profiler hooked with `sys.setprofile` counted nothing, because the MCP layer runs sync tools in a worker thread. `tests/perf_ratchet.py` hooks every thread, and a planted extra call was seen to raise the count.
- 2026-10-18 — A sweep's per-run working directories sat under a path the leak scan treats as a leak (`agent_qa`), so 28 alt runs that wrote scripts into their own cwd were marked invalid. Class: a harness path chosen without running the scan's patterns against it. `analyse.transcript_text` now replaces the run's own cwd before scanning, and `test_the_leak_scan_ignores_the_runs_own_cwd_but_not_its_siblings` checks a sibling path still counts.
